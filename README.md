# Sinytra Connector (Reference Fork)

### Branch: 1.20.1

> [!NOTE]  
> This repository is a static upstream fork maintained strictly for basic code reference and archetypal inspiration for **Fabricated**. It is independent of the main Sinytra ecosystem.

## 📖 About Upstream

**Sinytra Connector** is a translation/compatibility layer designed to run Fabric mods on NeoForge. The code in this repository serves as a baseline example of cross-runtime bytecode translation, mapping transformations, and platform bridging in the Minecraft ecosystem.

* Official Upstream Repository: [Sinytra/Connector](https://github.com/Sinytra/Connector)
* Documentation & Plugins Guide: [moddedmc.wiki](https://moddedmc.wiki/en/project/connector/latest/docs/plugins)
